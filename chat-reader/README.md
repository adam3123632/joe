# 听笺 · ChatGPT 阅读助手（电脑端）

在 ChatGPT 网页里增加回答目录、长文折叠和系统语音播放器。适用于电脑 Chrome / Edge，无需复制聊天稿件，也不需要 API 密钥或配音订阅。

[下载电脑端安装包](https://adam3123632.github.io/joe/chat-reader/tingjian-chat-reader.zip)

## 安装

1. 下载 `tingjian-chat-reader.zip`，解压到一个固定文件夹（安装后不要移动或删除）。
2. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后含有 `manifest.json` 的 `tingjian-chat-reader` 文件夹。
5. 刷新已打开的 ChatGPT 页面，在右下角点击「目录 · 朗读」。

这是可审查源码的本地扩展，尚未上架浏览器商店。ZIP 需要先解压，不能直接拖入安装。安装一次后，新打开的 ChatGPT 页面会自动启用；更新时用新文件替换文件夹内容，在扩展管理页点击「重新加载」，再刷新聊天页。

## 怎么用

- 约 600 字以上的已完成回答默认收起；点回答旁的「展开全文」恢复。原文、用户输入和 ChatGPT 的原生按钮保留。
- 右下角目录列出当前页面已加载的助手回答。点回答定位，点章节标题跳到相应段落。上方未加载的历史聊天需要先手动向上滚动加载，再刷新目录。
- 点「朗读」启动系统语音。支持暂停 / 继续、停止、上一段 / 下一段、拖动文字进度、倍速、音色和 0–100% 音量；页面会高亮当前段落，可关闭「跟随朗读」。
- 正在生成的回答保持展开，完成后才能朗读。切换聊天或被朗读的正文发生变化时，会停止本助手的播放。
- 倍速、音量、音色、折叠选择与文字进度保存在本机。重新打开后需主动点播放，不会自动出声。正文更新后不沿用旧进度。

## 语音的实际能力

播放器使用浏览器 Web Speech API，与 ChatGPT 自带的「朗读」是两个独立播放器。此扩展无法接入、定位或同步 ChatGPT 原生朗读的音频；使用原生朗读时，本助手的进度与高亮不会跟随。

音色与自然度取决于电脑已安装和浏览器提供的声音。某些系统声音需要联网，由浏览器 / 系统语音服务处理朗读文本。没有可用中文音色时，请在系统语言设置里安装中文语音。建议一次只用一个播放器。

进度按文字位置计算，不是音频时间轴；拖动后会从附近的可朗读词句重新开始，可能重复当前词。有字词边界事件时按词更新高亮，否则按分句更新。音量上限受电脑和浏览器音量限制。

## 数据与权限

仅匹配 `https://chatgpt.com/*` 和 `https://chat.openai.com/*`，只读取当前页面已渲染的助手回答。不读取账号密码、Cookie 或其他网站，不请求后台聊天接口，也不把聊天正文上传到本项目服务器。

唯一额外权限为 `storage`。扩展保存偏好、聊天路径 / 回答 ID、折叠状态、文字指纹和进度，不保存回答全文。卸载扩展会清除这些本机数据。系统语音是否联网由所选音色决定。

## 开发与验证

仓库根目录执行（Node.js 24）：

```sh
npm install --package-lock=false
npm run typecheck
npm test
npm run build:chat-reader
npm run test:chat-reader
```

产物为 `build/chat-reader-extension/` 与 `build/tingjian-chat-reader.zip`。浏览器测试默认使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定可执行文件。

测试使用模拟 ChatGPT 页面及可控语音事件，验证折叠、定位、段落高亮、续读和偏好恢复，另包含真实 MV3 扩展加载回归。若机器管理员明确禁止安装扩展，真实安装项会单独报告跳过，不计为通过；其他失败仍会导致测试失败。

当前云环境的 Chromium 管理策略禁止安装扩展，因此已验证页面功能和语音控制逻辑，未验证这里的真实安装或你的登录账号与电脑声音。ChatGPT 页面结构若变动，可能需要适配；可随时在扩展管理页停用或删除助手。
